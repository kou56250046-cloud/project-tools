# 案件ワークベンチ P6c 議事録の前処理・チャットのメモ・マスキング — 要件

ロードマップ: `~/.claude/plans/claude-code-pc-pc-gemini-notebooklm-pc-h-imperative-newell.md` の P6-2 と、gemini-kit の統合（前処理・マスキングのタブ）

## 背景
- Teams や Google Chat のやりとりをメモとして保管し、まとめて JSON で書き出して NotebookLM・Gemini に読ませたい（ユーザー）
- gemini-kit には、会議の文字起こしを 1 行 1 発言に整える前処理（clean.js。Teams の VTT・txt、Meet、話者:本文）と、表のマスキング（mask.js）がある。チャットの形式には対応していない（調査で確認）
- 段階的な統合で、前処理とマスキングもワークベンチへ移す

## 受入条件

### 議事録の前処理（道具の画面「議事録の前処理」）
- [ ] AC-01 文字起こしのファイル（txt・vtt。UTF-8 / Shift_JIS）を選ぶか貼り付けると、1 行 1 発言（`時刻 話者｜本文`）に整える。対応する形式は gemini-kit と同じ 5 つ（Teams の VTT・Teams の時刻つき・Teams の見出しの形・Meet・話者:本文）
- [ ] AC-02 判定した形式・判定できた行の割合・話者ごとの発言数を出す。割合が 0.8 未満なら「形式が想定と違う可能性があります」と出す
- [ ] AC-03 結果を `.clean.txt` で保存・コピーできる。「メモとして台帳に入れる」で、そのままメモ（AC-05）にできる（台帳が無いときは押せず理由を出す。50,000 字を超えるときは確認のうえ「題名（1/N）」の N 件に分ける）。複数のファイルを一度に選べ、ファイルごとに結果を出す
- [ ] AC-04 前処理の結果は、メモにしない限り保存しない（ロックで消す）

### チャットのメモ（新しい種別 memo）
- [ ] AC-05 台帳に新しい種別「メモ」（ID の頭は MM）を足す。持つもの: 題名・種類（チャット / 会議の文字起こし / その他）・場所（チャンネル名など）・期間（始め・終わりの日）・タグ・本文（1 行 1 発言に整えたもの）・関連する項目
- [ ] AC-06 メモの画面で、チャットの貼り付けからメモを作れる。貼り付けを design.md の「チャットの読み取り」の決まりで読み、日時・発言者・本文に分けて見せてから保存する。「編集済み」・リアクションの数・「返信」などの飾りの行は落とす。読めなかった行は本文のまま残し、件数を出す。design.md の例の表の入力が、期待する lines になる
- [ ] AC-07 1 つのメモの本文は 50,000 字まで（超えると保存しない）。案件のメモの本文の合計が 300,000 字を超えたら、メモを足す前に警告を出し、設定の保存の大きさの欄に合計を出す。メモは消せる（取り消し・記録の対象。メモを指す関連は外す）
- [ ] AC-08 メモの一覧（種類・場所・期間・タグで絞り込み）と、選んだメモをまとめて JSON と md で書き出す。書き出しは design.md の形
- [ ] AC-09 指示文の目的に「メモからの取込」を足す。選んだメモの本文（合計 60,000 字まで）を資料として入れ、台帳の一覧（メモを除く全種別）も載せて、決定・課題・質問の追加と既存の項目の更新を返させる
- [ ] AC-10 メモは社内のものとして扱う: 説明用の表示ではメモの画面を出さない。メモは design.md の「台帳の項目として扱う種別」の表のとおり、一覧・概要の件数・指示文の台帳の状態・変更の影響・gemini-kit 用カルテ・ダッシュボード・健康診断の項目ごとの点検に出さない。Gemini の差分でメモを足したり変えたりはできない
- [ ] AC-11 台帳の版は 2 のまま。メモを持たない台帳は前のツールでも読める。前のツールで同じ保存を開くと、メモを持つ案件だけが退避に移り、消えない

### マスキング（道具の画面「マスキング」）
- [ ] AC-12 表（CSV・TSV の貼り付け、または P6b の読み取りで xlsx・csv のファイル）を読み、列ごとに伏せ方を自動で選ぶ。伏せ方は gemini-kit と同じ 10 種（メール・仮名・連番・丸め・範囲・相対の日付・都道府県まで・空にする・列を消す・そのまま）で、列ごとに選び直せる
- [ ] AC-13 伏せた表を TSV・CSV で保存・コピーでき、対応表（元の値と伏せた値）を CSV で保存できる。対応表は保存しない（画面を開いている間だけ。ロックで消す。「対応表を空にする」で消せる）。ファイル名は design.md の表のとおりで、.gitignore で除く
- [ ] AC-14 「そのまま」の列に残っていそうな個人・会社の情報（会社の種類・メール・電話・郵便番号・様・殿、伏せた元の値）を警告する

## 非目標
- Teams・Google Chat と API でつなぐこと（貼り付けだけ）
- チャットの画像・添付ファイル・絵文字のリアクションの中身・スレッドの構造（返信の親子）を残すこと
- メモの本文の自動要約（要約は指示文で Gemini にさせる）
- メモを暗号化せずに保存すること（台帳と同じ箱に入る）
- 対応表を保存して、あとで元に戻すこと
- マスキングの規則を自分で足すこと、文章（表でないもの）のマスキング
- Zoom・Slack の形式
- 前処理を議事録の作成（P8）までつなげること
- 書き出したメモの JSON を読み込んで台帳に戻すこと
- 読み取った行を保存する前に画面で直すこと、同じ期間を 2 回貼ったときの重なりを除くこと
- メモの本文をあとから編集・分割・結合すること（消して作り直す）
- ファイル名から日付・回を推定すること
- Gemini の差分でメモを足す・変えること、Gemini が作る項目の関連にメモの ID を入れさせること
- 台帳の版を上げること

## 制約
- P1〜P6b の制約をすべて引き継ぐ
- gemini-kit の clean.js・mask.js は、写した元をファイルの頭に書き、ES module に書き直す。名前の衝突（RE・T・num・apply など）は付け替える。マスキングの画面の style 属性は class にする
- 種別を足すときは、前のツールで開いても上書きで消えないこと（退避の仕組み）を確かめる
