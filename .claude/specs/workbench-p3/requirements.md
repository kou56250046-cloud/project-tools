# 案件ワークベンチ P3（計画・進捗・報告） — 要件

前提: P2（`.claude/specs/workbench-p2/`）が済んでいる（版 2・変更の記録・2段の画面切り替え）。

## 背景

- 要件はたまるが、それをどの作業で実現し、いつ終わるかが台帳とつながっていない
- 進捗の報告（定例会資料・週報）を毎週手で作っている。台帳と変更の記録があれば大半は自動で作れる
- 要件が変わったとき、影響する作業と追加工数を説明する材料を毎回探している
- 顧客と画面を共有するとき、社内向けのメモやリスクを見せたくない

## 受入条件

### WBS
- [ ] AC-01 種別「作業」（TK）を足す。親の作業・見積（人日）・実績（人日）・担当（関係者）・開始日・終了日・進捗（0〜100%）・前の作業（作業 ID の配列、終了→開始）・マイルストーンの印を持つ。links で要件などとつなぐ
- [ ] AC-02 WBS 画面で、作業を階層の表で出す。親の見積・実績・進捗は子から自動で集計する（進捗は見積で重みづけ）
- [ ] AC-03 指示文の目的「WBS の作成」を足す。要件・決定・制約から作業を洗い出させ、要件とつなげて返させる
- [ ] AC-04 指示文の目的「進捗の更新」を足す。週次の報告文やメモから、作業の進捗・実績の update を返させる
- [ ] AC-05 WBS 画面で、末端の作業の進捗と実績をその場で入力できる（この2項目に限る）。取り消しと変更の記録の対象

### ガント
- [ ] AC-06 ガント画面で、作業を日付の横棒で出す。今日の線・進捗の塗り・マイルストーン（菱形）・前の作業からの矢印を出す
- [ ] AC-07 予定より遅れている作業（今日の時点で、期間の経過割合 − 進捗 が 20 ポイント以上）を色と文字の両方で示す
- [ ] AC-08 表示の幅を「週 / 月」で切り替えられる

### EVM
- [ ] AC-09 進捗画面で、今日の時点の BAC・PV・EV・AC・SPI・CPI・完了時の見込み（EAC = BAC / CPI）を出す。AC が 0 のとき CPI と EAC は「—」
- [ ] AC-10 PV・EV・AC の推移（S カーブ）を折れ線で出す。PV は予定から日ごとに計算する。EV と AC は変更の記録から、進捗・実績が変わった日ごとの値を復元する（追加時の値も記録する）。記録を 2,000 件で切るときは、捨てる記録から作業ごとの最後の値を1件の起点として残し、それより前の日は描かずに「記録の始まり」と表示する
- [ ] AC-11 SPI または CPI が 0.9 未満のとき、健康診断に「高」として出す

### 変更管理
- [ ] AC-12 種別「変更要求」（CR）を足す。対象（links）・内容・依頼者・追加工数の見込み（人日）・状態（起票 / 承認 / 却下 / 取り下げ）を持つ
- [ ] AC-13 変更要求の詳細で「影響範囲」を出す。対象の項目から、参照フィールドと関係を 2 段までたどって、作業・決定・課題・質問・（P4 以降は設計の項目）を種別ごとに並べ、影響する作業の見積の合計を出す。関係者とシステムは影響範囲に含めるが、そこから先へはたどらない（担当者つながりで無関係な作業が入らないように）
- [ ] AC-14 「変更要求書の下書き」をコピーできる（対象・内容・影響範囲・影響する作業と見積・追加工数の見込み）
- [ ] AC-15 指示文の目的「変更の影響レビュー」を足す。変更要求と影響範囲を入れ、見落としと追加工数の見立てを返させる

### 定例会資料・週報
- [ ] AC-16 定例会画面で、期間（前回の会議の日 〜 今日、または日付指定）を選ぶと、その期間の変更（追加・完了・状態の変化）、EVM、遅れている作業、顧客待ちの質問・課題、新しい決定、次回までの作業（期間の後 2 週間に終わる予定の作業）を1画面にまとめて出す
- [ ] AC-17 同じ内容から、週報の文面（メールや Chat に貼る平文）をコピーできる
- [ ] AC-18 指示文の目的「週報の清書」を足す。文面を Gemini に整えさせる（差分は返させない）

### 説明用の表示
- [ ] AC-19 全種別に「社内のみ」の印を持てる。詳細パネルで切り替えられる
- [ ] AC-20 上部の切り替えで「説明用の表示」にすると、全画面で次を隠す。上部に「説明用の表示中」と出る
  - 社内のみの項目そのものと、それへの参照（詳細パネルの関連・逆参照・ID のボタン・題名）。参照は「（社内のみ）」とだけ出す
  - 課題の重要度、健康診断（画面・タブの件数・概要の次にやること）
  - 実績に当たる値（作業の実績の列・AC・CPI・EAC）
  - P5 以降: 案件の切り替えの一覧（今の案件だけ出す）と横断の画面
- [ ] AC-21 説明用の表示中は、指示文・取込・設定の画面を開けない（URL の # で直接開こうとしても概要に戻す）
- [ ] AC-22 前回の会議は「開催済み（held）の定例（regular）のうち、今日より前で最も新しいもの」。無ければ 7 日前から

## 非目標

- 資源の山積み・平準化、担当者の負荷グラフ
- クリティカルパスの計算（前の作業の矢印は表示だけ）
- 作業のドラッグでの日程変更
- 金額（円）での EVM。工数（人日）だけ
- 祝日・稼働日カレンダー（日付は暦日で数える）
- 変更要求の承認フロー（状態を変えるだけ）
- 定例会資料の PDF・スライド化（画面で見せる）
- 週報の自動送信
- 過去の任意の時点の台帳の復元（S カーブに要る進捗・実績の値だけ記録から復元する）

## 制約

- P1・P2 の制約をすべて引き継ぐ
- 版 2 のまま種別と項目を足す（任意項目なので移行は不要。`schemaVersion` は上げない）
