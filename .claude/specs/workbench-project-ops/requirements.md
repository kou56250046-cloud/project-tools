# 案件ワークベンチ 案件の操作（リセット・合言葉の変更・多段の取り消し・上部からの追加） — 要件

## 背景
- 試しに使った案件や、方針が大きく変わった案件を、案件名や設定は残したまま最初からやり直したい
- 合言葉を変える手段が無い（忘れたときに全部消す入口しかない）
- 取り消しが直前の 1 回だけで、続けて取り込んだ後に前の誤りに気づくと戻せない
- 新しい案件を作るには「道具」→「設定」まで行く必要があり、遠い

## 受入条件

### 案件の中身を空に戻す
- [ ] AC-01 「設定」の「この案件」の欄に「中身を空に戻す」がある。押すと確認が出て、型（業務システム新規・基幹システム刷新・パッケージ導入・型を使わない）を選び直せる
- [ ] AC-02 空に戻すと、項目・関係・ベースライン・変更の記録が消え、案件情報（案件名・顧客・目的・期間・ゴール・概要）と「この案件の設定」は残る。選んだ型の質問が入る。採番は 001 からやり直す
- [ ] AC-03 確認の文に、消える件数（項目・関係・ベースライン）と最後の書き出しの日時を出す。未書き出しの変更があれば「先に書き出してください」と出す
- [ ] AC-04 空に戻した後も「取り消し」で元に戻せる（AC-09 の取り消しの1段として扱う）。revision は +1 され、未書き出しになる

### 合言葉を変える
- [ ] AC-05 「設定」に「合言葉を変える」がある。今の合言葉・新しい合言葉・新しい合言葉（確認）を入れる。新しい合言葉は 8 文字以上
- [ ] AC-06 今の合言葉が違うときは「今の合言葉が違います」と出て、何も変わらない
- [ ] AC-07 変えると、全案件と退避データが新しい合言葉で暗号化し直される。再読み込みすると新しい合言葉で開け、古い合言葉では開けない
- [ ] AC-08 暗号化し直しの途中で失敗したときは、古い保存を残し（上書きしない）、失敗を画面に出す

### 多段の取り消し
- [ ] AC-09 取り消しは案件ごとに直近 20 段まで。上部の「取り消し」を押すたびに 1 段ずつ戻る
- [ ] AC-10 上部の「取り消し」の横に「履歴」があり、押すと直近の変更の一覧（いつ・どこから〔取込・画面・ヒヤリング・設定・リセットなど〕・何件）が出る。一覧の行の「ここまで戻す」で、その変更の前まで一度に戻せる（確認つき）
- [ ] AC-11 取り消しの段は再読み込み・案件の切り替え・ロックで消えない範囲を今と同じにする: 再読み込みとロックで消え、案件を切り替えて戻ったときは残る
- [ ] AC-12 書き出した後の状態より前に戻ったら未書き出しになる（今の1段の取り消しと同じ考え方）

### 上部からの追加
- [ ] AC-13 上部の案件名の横に「＋ 新しい案件」がある。押すと案件名と型を入れる小さな画面が出て、作ると新しい案件として開く。今の案件はそのまま残る
- [ ] AC-14 説明用の表示中とロック中は「＋ 新しい案件」を出さない。台帳が無いときは出す（合言葉を決めてから作る）

### 使い方
- [ ] AC-15 使い方の文章（画面ごとの説明・よくある困りごと・最初の 10 分）とようこそ画面の文言を、上の4つに合わせて直す（取り消しが1回だけという記述を直す等）

## 非目標
- やり直し（取り消した操作をもう一度適用する）。「ここまで戻す」も元に戻せない（確認で知らせる）
- 取り消しの段を保存して、再読み込み後も戻せるようにすること
- 案件の一部（種別ごとなど）だけを空に戻すこと
- 案件情報や設定まで含めた完全な初期化（それは案件を外して作り直す）
- 合言葉の強さの判定・有効期限・忘れたときの復元
- 上部からのファイルの読み込み（読み込みは「設定」のまま）
- 別のタブで同じツールを開いたままの合言葉の変更への対応（先に閉じるよう案内する）

## 制約
- P1〜P5 の制約をすべて引き継ぐ
- 合言葉と鍵は保存しない。合言葉の変更でも、平文がブラウザに残らないこと
- 取り消しの段はメモリにだけ持つ（20 段 × 台帳の大きさ。目安として 500 項目の台帳で 20MB 未満）
